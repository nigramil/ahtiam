# Weather Diary

Автор: Аглиуллин Ахтям

## Описание

Weather Diary — это графическое приложение на Python, позволяющее пользователю вести дневник погоды. Вы можете добавлять записи с датой, температурой, описанием погоды и информацией об осадках, сохранять и загружать данные из JSON-файлов, а также фильтровать записи по дате и температуре.

## Как запустить

1. Убедитесь, что установлен Python 3.x.
2. Скачайте или клонируйте репозиторий на свой компьютер.
3. Установите необходимые библиотеки (если они не установлены):
